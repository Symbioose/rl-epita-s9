# Soutenance visuelle

Ouvrir `index.html` dans un navigateur ou projeter `presentation.pdf` : **10 slides principales**.
Les **3 annexes** sont dans `annexes.pdf`, pour les questions du professeur.

Le fil : montrer une partie réelle, expliquer comment l’expert enseigne au modèle,
puis lire les résultats et une erreur. Les images de jeu sont des schémas fondés
sur les traces, pas des captures d’un moteur graphique.

`notes.md` détaille pour chaque slide : **MONTRER**, **DIRE**, **TRANSITION**.
Durée proposée : environ 12 minutes. Dans le HTML : flèches pour avancer,
`N` pour les notes, `F` pour le plein écran. Le HTML est autonome et fonctionne hors ligne.

Reconstruction après extraction de l’archive : `make slides pdf`.
Les graphiques sont recalculés depuis les 12 résumés de test complets.
